# clients

One folder per client. Copy `_template/` to start:

```bash
cp -r clients/_template clients/<client-slug>
```

Each client folder has:

- **brief.md** — goals, offer, audience, KPIs, scope.
- **deliverables/** — build files, reports, exports.
- **notes.md** — call notes, decisions, change log.

No logins, API keys, or PII here. Reference vault entries by name only.
