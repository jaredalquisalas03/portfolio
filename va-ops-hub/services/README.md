# services

One folder per service I deliver. Each has the same four subfolders:

- **sops/** — step-by-step processes (built from `00-core/sop-template.md`).
- **templates/** — reusable assets: workflows, copy, snapshots, prompts.
- **checklists/** — QA and launch checklists.
- **examples/** — finished, redacted builds for reference.

Current services: `ghl/`, `meta-ads/`, `email-sms/`, `booking/`.
